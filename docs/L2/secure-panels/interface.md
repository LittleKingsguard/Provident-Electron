## 0. Scope: the arrangement, and what this document does not fix

The pane's **arrangement** is this unit's whole question at L2: whether the sixth group arrives as a second hand-written entry in a fifth-name list (L1's E-1 as filed) or as a **projection of one table bound to the gate's union**, what each choice binds, what it costs, and what it makes impossible to get wrong again (§1-§3; D-23, D-35). ## 1. The decision: the roster is one table, typed exhaustively against `ToolGroup`

- **One author for the pane's group set.** The pane carries a **label table** keyed by group name, and its roster is the table's own key set in the table's own authoring order — never a second literal beside it (the `GROUP_LABELS` table in `src/renderer/secure-panels.ts` and the `GROUPS` projection taken from its own keys; D-23, D-35).
- **The table is typed `Record<ToolGroup, string>`,** `ToolGroup` reached by a **type-only** import from `src/main/security.ts` — the binding shape L1's F-3 names as the landed precedent, and the same idiom the pane already uses for `ExclusionState` — the `EXCLUSION_STATE` specifier it shares with `ToolGroup` on that one type-only import from `../main/security.js` (`src/renderer/secure-panels.ts`; D-23, L1 §8 F-3).
- **That annotation is the drift net, and it is a compile-time one:** a seventh member on the gate's union reddens `npm run typecheck` — a member of `brief.md` §6's four-leg floor — in the unit that adds it, which is D-11's own rule that a number or a name must not move without the row that reads it (S-1; D-11, D-26).
- **Why this arm and not L1's E-1 as filed:** E-1's two entries (`GROUPS` and `GROUP_LABELS`) leave the third copy a copy; the arrangement above removes the copy without adding a file, a route or a runtime edge (§2, §6; S-2..S-6).
- **The five landed rows are untouched by it:** the five entries keep their texts and their relative order, `data` is appended, and P-7 is the row that keeps them so (the label table's five landed entries, in `src/renderer/secure-panels.ts`; L1 §5, D-35).
