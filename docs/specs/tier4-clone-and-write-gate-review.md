### 13.5 `G-4`'s STATE, STATED IN FULL: HOME · WRITER · READERS · BOOT VALUE · TRANSITION WINDOW

### 13.6 THE READ-REFUSAL'S CARRIER AND RETURN SHAPE, AND THE NOMINATED TOKEN
