### 2.3 The value / carry rules — stated falsifiably

**Item 1 — WHAT THE CONTROL CARRIES, AND HOW.** **The carried value is the SETTING TOKEN, and its whole journey is
three steps: (a) the OPERATOR or AGENT dispatches the authored handler on a `button` — `provident.dispatch` with
the authored event and, optionally, a `jsonArgs` that is the token (the CLI's own `dispatch <target> <event>

**Item 2 — THE `String()` GATE, AND WHERE IT IS ALLOWED TO BE.** **The demo's landed handler bodies apply a
