## 1. What this unit decides — the grain, and the four options it rejects

- **THE DECISION IS TWO THINGS AND NEITHER IS USEFUL ALONE: the readings are SPLIT (D-301's option (a)) and the declared set is PARTITIONED BY SEAT (the fourth option this pass found).** `W` — the whole-tree reading — keeps its home, its tree, its three controls and its failure; what it loses is its **hand list**. `P` — the per-seat reading — is new, and it is the one that makes `D-301`'s unmovable rule mechanical (§2).
- **THE RULE DOES NOT MOVE, AND EACH TERM IS `D-301`'s**: an entry is still a **FILE carrying its own reason**, never a directory, never a prefix, never a glob (`ASM-BG-1`); **`B-2`'s three controls stay byte-identical** (D-301); and **one reading still covers the WHOLE tree** (`ASM-BG-2`), so no undeclared cross-module edit may pass.
- **WHAT THE TAX ACTUALLY IS, AND `D-300` NAMED IT**: the set `D-301` counted lives in **one module's L2 battery**, so any pass writing any path anywhere owes an entry **in a file another module's L2 owns** — six extensions in one session, each a delegation for a one-line edit (D-300, D-301). The keystrokes were never the cost; **the OWNERSHIP was**. That is why `(a)` as `D-301` states it is not yet a design: *"a pass declares what it touched"* removes the delegation only if the declaration lives where **that pass may write** — which is the fourth option, and the pair is this unit's answer.
- **REJECTED `(b)`, THE MACHINE-CHECKED DERIVATION FROM THE MAP'S CLAIMED PATHS — refused by two of `D-301`'s own bounds and by a measurement.** A map claim is a **PREFIX** — `tests/e2e/app-layout/`, `src/main/operator-settings/`, `scripts/`, `demo/pane-drag-demo/` are directories in `strata/modules.json` — so a set derived from it **admits every file a later pass drops under a claimed subtree**, which is `B-2(b)`'s near-miss by construction, the exact reason `D-301` refuses a declared CLASS. It also inverts the tax instead of removing it: **no module claims any `docs/` path and none claims a `strata/` path**, so the `docs/` and `strata/` entries `D-301` counted stay hand-authored while the **code** tree goes free — and it lets an undeclared cross-module edit pass by ownership, which `ASM-BG-2` forbids (D-301). Its per-pass cost is zero, and it buys nothing the row exists for.
- **REJECTED `(c)` ALONE, THE CHEAPER AUTHORING PATH — it treats the symptom and would buy the colour with the row's only failure.** A script that appends entries from a diff **cannot author a reason**, and the reason is the half the row exists for (D-301); it leaves the delegation standing, because the file it appends to is still another module's; and a script that fills a reason turns the union into a **census of the dirty tree**, which is a row that cannot fail — worth less than no row (D-74, D-301). **Its shape is adopted in §3 only where it cannot invent a reason**: the reading prints the offenders by name, so a pass learns what it owes from a red and adds one entry.
- **REJECTED A TOKEN IN THE EDITED FILE'S OWN HEADER** — the cheapest possible authoring path, dead on the corpus's own content: `package.json`, `package-lock.json`, `tsconfig.json`, `src/renderer/index.html` and three `demo/` PNGs are declared paths, and **a PNG cannot carry a token** (D-301's count, read there — D-43). A sidecar for the uncommentable half is the ledger again, with two mechanisms to keep true instead of one (D-45).
- **REJECTED THE RETURN ENVELOPE AS THE HOME**, which this unit's examiner raised as the cheap fix for the homes (E-1, E-3): `strata/.strata/returns/` is per-pass and never re-armed, and every layer already writes one (brief §3:53) — **but a return is written when the pass REPORTS and `B-1` must be green BEFORE the legs run**, so a declaration in it would have to precede the verdict it carries (envelope.md §2). The ordering kills it, not its cost.

A declaration therefore **dies at the commit that lands it** (D-1: git is the history) instead of becoming a standing permission.
- **AND THAT IS THE STRENGTHENING THIS UNIT OWES THE ROW**: today the set is 262 standing permissions, so an edit to any path in it passes with no declaration at all, whatever pass makes it (D-301's count, read there — D-43). After this design the declared set is the **in-flight** set and `P-5` refuses an entry for a path nobody touched.
- **WHY TWO READINGS AND NOT ONE, MEASURED RATHER THAN PREFERRED**: membership is exact string equality, so a **directory or a glob in the declared set is inert** — it matches no porcelain path, so `B-1` never names it and `B-2(b)` samples only **four** spellings. `D-301`'s unmovable rule therefore has **no mechanical witness today**, and `P-2` is that witness (E-9: rev 1 said three).

**`P`'s arms — seven, and each can fail.**

- **`P-1` THE READER IS TOTAL AND ITS HAPPY PATH IS DRIVEN**: over an edit set naming no declaration page it answers `[]` and does **not** throw; over a **fixture home** — `readInFlightDeclarations` takes `homes` as a parameter — it answers the blocks it finds, so a reader that always answered `[]` reds (E-8: rev 1's arm was satisfied by exactly that). A malformed `boundary-declared` block in an **in-flight** page throws and is never skipped (D-74: the response to a failure is never silence).
- **`P-2` AN ENTRY IS A FILE**: repo-relative, POSIX separators, no leading `/`, no `..` segment, no trailing `/`, no `*` `?` `[` `{`, and it names a **file** — present in the worktree, or tracked at HEAD when the entry declares a **deletion**. A directory spelling is refused **by name** (D-301).
- **`P-3` AN ENTRY CARRIES ITS OWN REASON**: `why` non-empty after trim **and** a `d` carrying a `D-n` that resolves against `strata/decisions.md`'s `## D-n` headers — the `refs` idiom, and D-1's provenance rule applied where a reason is now authored.
- **`P-4` A DECLARATION IS ITS SEAT'S**: the block's `layer`/`module`/`unit` matches the page's own location (§3), **`unit` names a unit the state ledger carries** (`strata/.strata/units/<unit>.json`), and every entry's `by` is the declaring layer **or `L4` inside an L3 declaration** — the one named exception, because L4 owns no design and receives the exact write it makes (brief §3, §4; E-3).
- **`P-5` NO STANDING PERMISSION**: every declared path is in the edit set, so a declaration cannot outlive its write and cannot be pre-filed for a later pass (`D-146`'s same-pass rule now reads **never before it either**).
- **`P-6` THE FALSIFIER — THE ROW CAN STILL FAIL**: one comparator driven over a **fixture** declaration carrying a directory, a glob, a clean path, a missing `why`, an unresolvable `D-n`, a wrong-seat page and a duplicate entry, each **refused and named**, and over a lawful fixture — including a `src/main/` entry — **admitted whole**. The live arms are vacuous on a committed tree and green on arrival, so **the falsifier is the load-bearing arm** (D-74, D-301).
- **`P-7` NO PATH IS DECLARED TWICE, AND THE DETECTOR NAMES BOTH PAGES (E-6)**: `declaredScope` keeps duplicates so `B-1`'s boolean can fail, and `P-7` names the path and both declaring pages — because a boolean whose message names nothing is the silence `D-74` refuses, and the second seat's fix (drop its own entry) is inside its own scope.

## 3. How a pass uses it — the authoring path, and its cost

- **ONE FENCED `boundary-declared` BLOCK IN A PAGE THE SEAT ALREADY OWNS AND IS ALREADY REVISING** — a *declaration block* in D-45's sense, kept only because **two rows compare it to the tree** (D-45 ii: a battery row, no new instrument, and per D-40 a row authored now gates). Body: `{"unit","layer","module","writes":[{"path","why","d","by"}]}`; `by` defaults to the block's `layer`.
- **WHERE, AND `P-4` IS THE TABLE**: L1 → `docs/L1/`; L2 → `docs/L2/<module>/`; L3 → `docs/L3/<module>/`; **L0 → `strata/` — its own pages and `strata/records/`**, because L0's routine writes are `strata/decisions.md`, `brief.md`, `pending.md` and the records, and a home that did not reach them left this tree's own charter-file undeclarable (E-1). **L4 declares nothing and its landing is declared by its L3 page with `by: "L4"`** (§2 `P-4`). A module page already at its class max takes a `<module>/boundary.md` page instead of an append (D-1, D-2).
- **A PATH AN INSTRUMENT WRITES IS DECLARED BY THE SEAT WHOSE PASS CAUSED THE WRITE**: the state file `strata/.strata/units/<unit>.json` (written by `strata-state`, brief §1:27), a return in `strata/.strata/returns/`, and `strata/marks.json` (written by `strata-marks.mjs index`, D-30) are **files like any other** — the state file belongs to the seat that took the transition, the return to the layer that wrote it, the index to the pass that regenerated it. **The instrument that wrote a path is never the seat that declares it** (D-146, D-301).
- **COST PER PASS, STATED AS THE THING THIS UNIT EXISTS TO CHANGE**: one edit **in the seat's own scope**, N entries, each a path plus one sentence — **no delegation, no prose block, no cross-module file** (D-300, D-301). The reason is the only authored thing, which is the half that must stay (D-301).
- **ITS THREE SEQUENCING COSTS, NAMED SO THEY ARE NOT DISCOVERED**: a supervisor commit **between** a declaration and its write makes the declaration inert and the write undeclared, and the fix is one entry, never a delegation; **a later pass that revises a page carrying a block re-arms it**, so that pass **replaces** the block with its own window's writes rather than appending beside it (D-1); and an L4 landing whose L3 page was committed before it reds `W` with no path for L4 to clear, so it bubbles (brief §4).
- **WHAT NO ARM CAN DO, SAID RATHER THAN IMPLIED (E-2)**: nothing attributes a declared path to the seat that wrote it. An entry is **not** confined to the declaring seat's module — a cross-module write is exactly what the row exists to declare — so the instrument's claim is that **silence is impossible and the reason is reviewable**, never that the writer is the declarer. That is `D-44`'s unverifiable class, and a design that pretended otherwise would be claiming a gate it cannot build (D-44, D-30).

## 6. What would make this design wrong

- **IF DECLARATIONS RATCHET AGAIN.** A page re-opened every session and never replaced returns the union to a standing allow-list, and `P-5` is the only thing that would say so. **A union whose entries are mostly clean paths means the in-flight rule is not being followed**, and the instrument has bought its convenience back with its teeth (D-301, D-30).
- **IF A PASS CANNOT DECLARE WHERE IT MAY WRITE.** Rev 1 had two such holes and rev 2 closes both (L0 → `strata/`, L4 → `by` inside its L3 page); a third — a seat whose scope holds no page at all — would red a row it cannot clear, and the answer would be a rebuild of §3, not a patch (E-1, E-3).
- **IF `git status` IS THE WRONG READING.** Both readings trust it, so a write that leaves no worktree trace is invisible to both. `W`'s blindness is inherited and unchanged; `P`'s is new only in that it inherits the same reading rather than inventing a second one (D-74).
- **IF `P-6` EVER PASSES WITH A BAD FIXTURE**, the row is vacuous and worth less than no row (D-74, D-301) — which is why the falsifier is an arm and not a comment, and why rev 1's undelivered happy-path arm was a blocker-grade finding (E-8).
- **IF THE LOOP DOES NOT READ THE DIFF AT THE COMMIT.** The instrument's whole claim is that **silence is impossible** and the reason is reviewable; **no row can enforce a reader**, and nothing here attributes a write to a seat (§3) — a design that pretended otherwise would be claiming the gate it cannot build (D-44, D-30).

## 9. What this unit does not do
